# Jagged Intelligence

> **Зубчатый интеллект (Jagged Intelligence)**

A phenomenon: an agent demonstrates exceptional results in some tasks and unexpected failures in adjacent ones. The boundary of competence is non-obvious and is not predicted by model size. Demands an architectural response: agent debates, cross-validation, confidence calibration. Could take shape as a standalone architectural principle.
