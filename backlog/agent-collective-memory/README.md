# Agent Collective Memory

> **Коллективная память агентов (Agent Collective Memory)**

When multiple agents work on related tasks, their memory should have a shared layer: one agent's decisions are accessible to another without explicit handoff. Potentially implementable through a shared vector database plus a session log. Not described in current patterns — a raw idea.
