# Agent Autonomy Progression

> **Прогрессия автономности агентов**

Four levels: (1) the agent executes explicitly assigned tasks without altering its behavior; (2) records observations and proposes improvements for human review; (3) independently introduces improvements within approved boundaries; (4) creates tasks for other agents, with the human providing final approval. Partially verified on Mac Mini (levels 2–3).
