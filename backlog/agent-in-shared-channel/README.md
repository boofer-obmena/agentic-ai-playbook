# Agent in a Shared Communication Channel

> **Агент в общем канале коммуникации**

An agent residing in a team's shared channel (chat, messenger) continuously listens to discussions and extracts architectural decisions, agreements, and patterns. It filters not individual messages but completed discussion threads. Potentially — a pattern for passive collection of project knowledge.
