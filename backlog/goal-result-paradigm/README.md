# Goal-Result Paradigm

> **Парадигма «цель-результат» (Goal-Result Paradigm)**

The Orchestrator does not return intermediate text to the human — it drives the task to logical completion: receives a goal → builds a plan → executes → sends the result. The human is removed from the role of a "live bridge" between steps. An extension of PATTERN-011.
