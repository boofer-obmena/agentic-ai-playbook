# Agent Self-Testing Before Deployment

> **Самотестирование агента перед развёртыванием**

Before updating rules or a prompt, the agent must pass a test battery — both regression tests (old scenarios are not broken) and tests specific to the change. Related to PATTERN-024 (Co-Testing) and PATTERN-025 (Three-Level Rules). Not implemented — at the idea stage.
