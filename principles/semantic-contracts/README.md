# Semantic Contracts

> **Управляемый жизненный цикл**

**Essence:**

Управляемый жизненный цикл: Статусы всех задач и артефактов изменяются исключительно как следствие формализованных операций-транзакций. Произвольное изменение состояния агентами исключено.
