# Input Quality Determines Output Quality

> **Качество входа определяет качество выхода**

An agent working with a knowledge base does not hallucinate — it reflects the information diet of its KB. Responsibility for KB quality lies with the architect, not the model. Populating a knowledge base requires high-quality indexing and curated source selection.
