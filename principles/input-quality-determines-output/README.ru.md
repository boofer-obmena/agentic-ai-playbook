Качество входа определяет качество выхода: Агент, работающий с базой знаний, не галлюцинирует — он отражает информационную диету своей KB. Ответственность за качество KB лежит на архитекторе, не на модели. При наполнении базы знаний важно обеспечивать качественную индексацию и кураторский отбор источников.
