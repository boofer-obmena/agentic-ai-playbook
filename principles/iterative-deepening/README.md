# Iterative Deepening

> **Управляемость важнее специализации**

> *[English translation pending. Original Russian text preserved in sections below.]*

## Essence

Принцип 1. Управляемость важнее специализации: Универсальность языковой модели достигается не усреднением знаний, а высокой степенью следования инструкциям (instruction following). Одна хорошо управляемая модель с качественным системным промптом способна закрыть большинство специализированных ролей. Управляемость — это предсказуемость, а предсказуемость — это безопасность.
