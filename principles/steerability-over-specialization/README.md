# Steerability over Specialization

> **Управляемость важнее специализации**

The universality of a language model is achieved not by averaging knowledge, but by a high degree of instruction following. A single well-steered model with a quality system prompt can cover most specialized roles. Steerability is predictability, and predictability is safety.
