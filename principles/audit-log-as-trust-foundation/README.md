# Audit Log as the Foundation of Trust

> **Журнал аудита как основа доверия**

Stakeholders will trust an autonomous agent in production only if every step it takes can be reconstructed and explained. A complete audit log — Trace History — is not a debugging tool, but a trust instrument. An agent without an audit trail is a black box that cannot be trusted.
