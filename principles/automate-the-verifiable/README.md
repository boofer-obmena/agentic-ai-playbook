# Automate the Verifiable

> **Автоматизируй верифицируемое**

An AI agent operates where the result can be verified — checked automatically. When designing a task for an agent, the first question is: "How will we verify the result?" If the result can be verified automatically, the task is suitable for an unsupervised agent. If not, Human-in-the-Loop is required.
