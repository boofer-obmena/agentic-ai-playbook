Автоматизируй верифицируемое: ИИ-агент работает там, где результат можно верифицировать (проверить автоматически). При проектировании задачи для агента первый вопрос — «как мы проверим результат?». Если проверка возможна автоматически — задача подходит для агента без надзора. Если нет — требуется Human-in-the-Loop.
