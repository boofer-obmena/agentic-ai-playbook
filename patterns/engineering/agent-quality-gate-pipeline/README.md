# Agent Quality Gate Pipeline

> **Паттерн И14. «Контроль качества в жизненном цикле агента» (Agent Quality Gate Pipeline)**

**Проблема: Качество агента оценивается субъективно — «выглядит нормально». При любом изменении системы (новый промпт, новое правило, обновление модели, изменение базы знаний) разработчик не знает, не сломалось ли то, что раньше работало. Деградация обнаруживается постфактум — пользователем.:**



**Решение: В жизненный цикл агента встраивается контур оценки качества с двумя механизмами.:**

Golden Set Regression — регрессионный барьер. Формируется курируемый набор эталонных пар «вход → ожидаемый выход» для задач, где ответ объективно известен. При любом изменении системы golden set прогоняется автоматически. Если результаты отклоняются от эталонов выше порога — изменение блокируется. Golden set не эволюционирует, а фиксирует стабильность: он предотвращает деградацию.

LLM-as-Judge — измеритель качества. Для творческих и аналитических задач, где эталонного ответа нет, качество оценивается отдельной LLM по заданным рубрикам (полнота, точность, соответствие формату, отсутствие галлюцинаций). LLM-as-Judge не говорит «правильно/неправильно», а даёт числовую оценку по каждому критерию. Оценки отслеживаются во времени — падение ниже порога сигнализирует о деградации.

Отличие от PATTERN-007 (Тест-кейс как артефакт): PATTERN-007 — детерминированный бинарный тест внутри конвейера для конкретной операции. PATTERN-051 — внешний контур оценки качества агента как целого, применяемый при изменениях системы.

**Пример: Разработчик меняет системный промпт агента-аналитика. До деплоя CI/CD-конвейер прогоняет golden set из 30 эталонных задач. 28 из 30 — в пределах допуска. Две задачи показывают отклонение: агент изменил формат ответа. Разработчик анализирует отклонения, корректирует промпт, перепрогоняет — все 30 в допуске. Изменение идёт в деплой.:**



**Связь с другими паттернами: Дополняет PATTERN-007 (Тест-кейс): PATTERN-007 — операционный тест внутри конвейера; PATTERN-051 — качественный гейт при изменениях системы. Дополняет PATTERN-024 (Замкнутый цикл тестирования): PATTERN-024 решает частную задачу; PATTERN-051 — общий механизм оценки.:**



**Экспериментальная проверка: Требуется. План: развернуть golden set из 20+ задач; измерить: корреляцию между оценкой LLM-as-Judge и экспертной оценкой человека, долю ложных регрессий.:**
