# Первичность итеративного самоуглубления над однопроходной генерацией

[Read in English](README.md)

Процесс создания знания — и человеком, и агентом — принципиально итеративен. Однопроходная генерация имитирует результат мышления, но не сам процесс мышления.

Когда методолог работает над материалом, он не пишет финальный текст за один присест. Он набрасывает черновик, затем отвлекается — сбрасывает контекст, чтобы вернуться к материалу свежим взглядом. Он обращается к книге, напрямую с темой не связанной, и через неё находит неожиданный ход мысли. Он перечитывает материал через час, через день, через неделю — и каждый раз видит то, чего не замечал раньше. Именно это чередование погружения и отстранения, генерации и критики создаёт глубину, недостижимую за один проход.

Архитектурное следствие: агентная система, имитирующая глубокую интеллектуальную работу, не должна строиться как конвейер однопроходных операций. Она должна предусматривать циклы — не как обработку ошибок, а как штатный режим работы. Итерация — не признак того, что что-то пошло не так. Итерация — это и есть то, как мышление устроено.

Этот тезис противостоит интуитивно привлекательной, но ошибочной идее «хорошая модель должна выдавать хороший результат с первого раза». Модель — лишь компонент мышления, а не его замена. Глубина рождается не в моменте генерации, а в пространстве между итерациями.

Эта философия не требует применять рефлексию одинаково ко всем задачам. Глубина итеративного углубления должна быть соразмерна критичности результата. Для операционных задач с низкой ценой ошибки однопроходная генерация уместна. Для задач средней критичности оправданы несколько итераций проверки. Для экспертных задач, где цена ошибки высока, рефлексия становится не опцией, а обязательным элементом процесса. Система не должна быть ни легкомысленной в критических ситуациях, ни параноидальной в рутинных.
