# Throughput over Capacity

> **Принцип пропускной способности над ёмкостью**

When designing any layer of the system, the critical parameter is not the volume of stored data, but how quickly it can be retrieved. A short, precise chunk retrieved quickly is preferable to a long, exhaustive one requiring slow parsing.
