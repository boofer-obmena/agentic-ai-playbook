# Semantic Density (Intelligence per Byte)

> **Принцип смысловой плотности («Интеллект на байт»)**

The quality of an agent's work is determined not by the quantity of data in its context but by the semantic density of each token. The goal is to maximize the amount of useful meaning carried per unit of context window.
