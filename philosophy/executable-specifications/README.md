# Executable Specifications

> **Принцип смысловой плотности («Интеллект на байт»)**

> *[English translation pending. Original Russian text preserved in sections below.]*

## Essence

Принцип смысловой плотности («Интеллект на байт»): Качество работы агента определяется не количеством данных в контексте, а смысловой плотностью каждого токена. Цель — максимизировать количество полезного смысла, передаваемого через единицу контекстного окна.

Следующие принципы относятся непосредственно к проектированию агентов и их взаимодействию.
